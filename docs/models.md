# Модели внутри Cursor для спринта «Цифровой механик»

Сводка на **20.11.2026**. Имена и цены — только с официальных страниц Cursor. Перед спринтом ещё раз откройте актуальные [Models & Pricing](https://cursor.com/docs/models-and-pricing) и [cursor.com/pricing](https://cursor.com/pricing): линейка и тарифы меняются.

Это рекомендация, **как пользоваться Cursor во время написания кода**. Модели самого агента «Цифровой механик» (Neuraldeep) описаны в `TZ.md` §8 и к этому файлу не относятся.

## 1. Что сейчас входит в планы

Источник: [Models & Pricing](https://cursor.com/docs/models-and-pricing), [Pricing and plans](https://cursor.com/help/account-and-billing/pricing.md). Cursor продаётся как часть «The X Subscription».

| План | Цена | Что важно для спринта |
|---|---|---|
| Free | $0 | Ограниченное использование, сторонних моделей нет |
| Plus | $8/мес (год: $80) | Только собственные модели Cursor: **Grok 4.7, Grok 4.6, Grok 4.5, Composer 2.5**. Фиксированные настройки: Fast выключен, effort medium, у Grok 4.7 окно 256k. **Нет** Auto, Cloud Agents, Automations, **Bugbot**, Origin, сторонних моделей и своих API-ключей |
| Premium | $30/мес (год: $300) | Всё из Plus, **4×** пула Plus. Добавляются Cloud Agents, Automations, Origin, **код-ревью Bugbot**, сторонние модели по API list price с предоплаченного кредита, Grok Bot |
| Super | $100/мес (год: $1 000) | Всё из Premium, **15×** пула Plus, приоритет в часы пик |
| Ultra | $200/мес (год: $2 000) | Всё из Super, **50×** пула Plus |
| Teams | $30 / $100 / $200 за место | Пул как у соответствующего уровня; сторонние модели + **Cursor Token Rate** $0,25 / 1M токенов на подходящих моделях |
| Enterprise | индивидуально | Пул общий; Router и Token Rate — по правилам команды |

На всех платных планах есть **один недельный пул** на модели Cursor (Grok 4.7 / 4.6 / 4.5 и Composer 2.5). Пул общий с Grok (чат, Voice, Imagine, Grok Bot). Он обновляется еженедельно. Разные модели расходуют пул с разной скоростью. Остаток смотрите в настройках редактора и на grok.com/dashboard.

Если у вас ещё **legacy-план** (Hobby, Start, Pro, Pro+, старый Ultra, Teams Standard/Premium), действуют два месячных пула (Cursor Models и Other Models) и on-demand вместо top-up. Смотрите раздел Legacy на той же странице цен.

**Для 48-часового соло-спринта:** Premium (или выше) удобнее, потому что есть Bugbot и Auto Cost. На Plus можно написать код на Composer 2.5 и Grok 4.7, но без Bugbot и Auto. Super/Ultra имеют смысл, только если недельного пула Premium не хватает на несколько параллельных агентов.

## 3. Auto и Router

Источник: [Cursor Router](https://cursor.com/docs/cursor-router), раздел Auto modes на [Models & Pricing](https://cursor.com/docs/models-and-pricing).

- **Cost** (прежний Auto): оптимизирует расход токенов; тарифицируется как запрос к модели Cursor и **берётся из недельного пула**; Cursor Token Rate не начисляется. На индивидуальных планах **есть только Cost**.
- **Balance** и **Intelligence**: доступны через Cursor Router на планах **Teams и Enterprise** (на Enterprise Router по умолчанию выключен). Биллинг — по list price той модели, куда ушёл запрос; сторонний маршрут плюс Token Rate (кроме моделей с cache-read строго ниже $0,10 / 1M на всех тирах). Расходуют лимиты быстрее, чем Cost.

Plus, по таблице планов, **не включает Auto**. Premium и выше — включают (индивидуально: Cost).

## 4. Сторонние модели (Premium+)

На Premium и выше доступны сторонние модели (в документации как примеры названы Claude, GPT, Gemini) **с первого запроса по API list price**, с предоплаченного кредита. Они **не входят** в недельный пул. Полная таблица — на [Models & Pricing](https://cursor.com/docs/models-and-pricing) (в ней, среди прочих, есть линейки Claude 4 / 4.5 / 4.6). Для спринта их **не обязательно включать**: качество кода на Composer 2.5 и Grok 4.7 достаточно, а сторонние модели съедают отдельный кредит. Если всё же понадобится «тяжёлая» проверка архитектуры на Premium — берите конкретную модель из официальной таблицы, не из памяти.

На Teams/Enterprise к подходящим сторонним моделям добавляется Cursor Token Rate $0,25 / 1M. На индивидуальных планах этой ставки нет. Модели Cursor и режим Cost ставки не несут.

## 5. Bugbot (код-ревью PR)

Источники: [Bugbot](https://cursor.com/docs/bugbot), [Bugbot usage-based billing](https://cursor.com/help/account-and-billing/bugbot-usage-based-billing), [страница Bugbot](https://cursor.com/bugbot).

- Входит начиная с **Premium** (на Plus нет).
- С 11 мая 2026 для новых клиентов — **оплата по использованию**, не за место. Для старых клиентов переход — со следующего цикла после 8 июня 2026 (или раньше добровольно).
- **Средний прогон ревью PR: около $1,00–1,50**, зависит от размера и сложности.
- Уровни effort: Low (дешевле, дольше), Default, High (дороже, может найти больше ошибок), Smart (выбор уровня по инструкции).
- На Individual: сначала included usage, затем on-demand, если включён; иначе Bugbot встаёт до сброса цикла.
- Ручной запуск: комментарий `cursor review` или `bugbot run` в PR.
- Слишком большой PR Bugbot пропускает, такой прогон **не тарифицируется**.

Это официальный инструмент ревью в Cursor. Отдельной «модели Bugbot» в каталоге моделей нет — в документации он описан как продукт ревью, а не как строка в таблице Composer/Grok.

| Фаза | Что делать в Cursor | Модель | Почему |
|---|---|---|---|
| 1. Fast ($3 / $15) брать только если стандарт заметно «тупит» по скорости |

| 8. Код-ревью | PR в GitHub/Origin + проход по чувствительным местам в чате | **Bugbot** (Default, Premium+) на каждый осмысленный PR; в редакторе — **Grok 4.7**, промпт `docs/prompts/08_review_refactor.md`. Если план **Plus**: весь спринт на **Composer 2.5** и точечно **Grok 4.7** (Fast всё равно выключен настройками Plus). Bugbot недоступен — ревью только вручную промптом 08 и моделью Grok 4.7.

## 7. Чего не делать

- Не включать **Composer 2.5 Fast** и **Grok Fast** «на всякий случай»: за ту же работу пул кончится в разы быстрее.
- Не брать **Grok 4.7 500k**, пока в контекст не нужно класть очень большие файлы.
- Не сажать весь спринт на сторонние Claude/GPT/Gemini: они не входят в пул и с первого запроса идут по list price.
- Не выдумывать имена моделей («GPT-5», «o3», старый «Composer 1» и т.п.): в Cursor выбирайте только то, что видно в model picker и на странице цен.
- Не путать модели Cursor с моделями Neuraldeep: в продукте хакатона tool-loop — `qwen3.6-fp8`, гипотезы — `qwen3.8-27b`.
