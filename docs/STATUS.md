## Решения

- **`RAG_MIN_SCORE` = 0.80, оставлен.** Ниже порога нельзя: у N01 лучший фрагмент 0,691, у N02 0,730, у Q03 0,730. При пороге 0,6 «нет инструкции» перестанет работать.
- **Q03 — известный промах.** Не чинится порогом, в работе не стоит.
- **N03 переименован в Q12** (позитивный, эталон стр. 43: гидротолкатели исключают регулировку зазоров). Старый N03 был ошибочно размечен: top-1 0,985 — стр. 25, зазор свечей, а не клапанов. Новый N03 — «интеркулер» (нет инструкции); top-1 проверит стенд.
- **X01 и давление масла.** Правила `yamz236_valve_clearance_timing` и `yamz236_oil_pressure` в `data/known_conflicts.yaml` приняты командой. Письменного решения заказчика в репозитории нет (документы заказчика вне репо, п. 9.1). Безопасный вариант давления: 400–700 кПа.
- **Противоречия руководства (решение заказчика).** Показываем обе формулировки со ссылками и безопасное правило, как и раньше. Фраза «уточните у специалиста» убрана везде: механик сам специалист.
- **Нет в руководстве (решение заказчика, этап 07a).** Первая строка «В руководстве на <двигатель> этих данных нет.», затем «Что сделать». Общие сведения необязательны и только качественные: блок с числом с единицей или нумерованными шагами код вырезает и считает метрику.
- **Голос (этап 08): ru по умолчанию.** `STT_LANGUAGE` (ru, uz, kk, tg, ky, en; пусто — автоопределение) и поле формы `lang`. Ответ и журнал пишут фактический язык. Согласие хранится в браузере (`voice_consent_at`), сервер проверяет только его наличие: таблицы согласий нет, она появится с PIN-входом (этап 09). Аудио не сохраняется; в журнал пишутся модель, размер, длительность, ₽ и код ошибки, без байтов записи.
- **Тег `mvp-f1-f7`** на `e2ef54d`, запушен.
- **Тег `mvp-ocr-ui`** на `ec99bac`: этап агента, OCR и мобильного UI. Временные `/admin/ocr/*` в этом теге ещё есть (удаляются на этапе 10).

## Известные проблемы

- **Q12 и новый N03 не проверены на стенде.** Top-1 для них нужен прогон RAG (Neuraldeep недоступен с рабочей машины). Если Q12 не попадёт в top-5, это промах поиска, а не ошибка эталона.
- **Голос не проверен на стенде полностью.** Русский распознан на стенде. Нет проверки `whisper-1` в `GET /v1/models` (Neuraldeep недоступен с рабочей машины). Языки uz/kk/tg/ky на whisper-1 не проверены: возможен отказ модели по коду языка. Ход с `input_mode=voice` виден в `/admin/logs` (колонка «Ввод»); сбой записи в журнал пишется в лог приложения, текст при этом возвращается.
- **Q03: промах hit@5** (см. решения).
- **Neuraldeep недоступен с рабочей машины** (таймауты TLS на `api.neuraldeep.ru`). Прогоны только со стенда.
- **Стенд недоступен с рабочей машины.** `/admin/eval` и `/admin/ocr/*` вызывает пользователь. Eval `suite=agent` использует `MemoryJournal`, поэтому его прогоны не попадают в `agent_runs`.
- **Порт 8000 на рабочей машине занят Docker Desktop** (`com.docker.backend`, `wslrelay`). Помогает перезапуск Docker Desktop.
- **Материалы задачи не в git (п. 9.1).** Заглушки, PDF и документы заказчика берутся по ссылке из env: `MATERIALS_URL`, `MANUALS_URL`, `MOCK_DATA_URL`. Перед деплоем ссылку положить в панель Timeweb (см. `docs/deploy.md`). `/health` показывает `materials: ok|missing`.
- **Без `DATABASE_URL`** журнал, заявки и состояние диалога живут в памяти процесса. История диалога в чекпойнтере растёт без обрезки.
- **Утечка строки подключения к БД.** Ранее строка подключения попала в вывод чата. Пароль нужно сменить, если это ещё не сделано.
- **Отчёты прогонов в git — только метрики.** Поле `report_md` в `GET /admin/eval/status?run_id=` содержит метрики, ID, статусы, страницы и стоимость (можно копировать в `eval/*.md`). Полный отчёт с фрагментами и ответами хранится в `report_full_md` (БД) и показан в `/admin/logs`. Ручные выгрузки `eval/reports/agent_run_*.md` в `.gitignore`.
- **Цитаты агента в прогоне run 7 (`38e176e`, 4 из 5), исправлено в `ec99bac`, подтверждено run 8 (5 из 5).** C1: модель дала стр. 46 вместо стр. 19/267 с той же цифрой. Код заменял ссылку только до регенерации, и фразу вырезало. Исправлено: ссылка заменяется кодом и после регенерации (шаг `citation_fixed` с `from`/`to`), заглушка «не подтверждено» после фразы без норматива убирается, проверка цитат идёт по финальному ответу, ошибки сырого ответа модели выводятся метрикой в отчёте. Прогон на `ec99bac` подтверждён.
