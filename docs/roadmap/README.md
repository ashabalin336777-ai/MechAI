# Развитие проекта: концепции мобильного интерфейса

Этот каталог — направление после MVP. Здесь концепции, а не реализация. Что уже работает в продукте и что запланировано по этапам, см. [docs/STATUS.md](../STATUS.md).

## Слайд: 5 вариантов мобильного UI

Файл: [overview_all_5.png](overview_all_5.png). Размер экрана 390×844, сценарий S1 («Отклонение давления масла»).

| Вариант | Экран | Идея |
|---|---|---|
| A · Индекс состояния | главная машины | индекс отклонения 0–1 со шкалой, «что основной вклад» (виброскорость, давление масла, уровень масла), динамика за 30 суток, кнопка «Спросить агента и оформить заявку» |
| B · Чат с агентом | диалог | лента с видимыми вызовами инструментов (`get_diagnosis`, `search_manual`), ссылки «документ + страница», быстрые действия: ввести замеры, голосом, фото манометра |
| C · Запись звука | диагностика по звуку | запись работы двигателя, таймер, статус датчика, кнопка «Остановить и анализировать», результат «Не эксплуатировать» и спектр |
| D · Заявка в ТОиР | список заявок | статусы заявок («ждёт подтверждения», «черновик»), подтверждение отправки после галочки |
| E · Пошаговый (гараж) | режим для механика у машины | один шаг на экран, крупные поля замеров (давление масла по манометру), кнопка «Дальше», текст для новичка |

Слайд показывает расширение на парк ГАЗель Next (машина «ГАЗель Next · В112КМ 154» в шапке). В текущих данных проекта такой машины нет: парк в `mock/data/vehicles.json` — МАЗ, Урал, ПАЗ, УАЗ и двигатели ЯМЗ и ЗМЗ.

**Внимание к данным.** На слайде указаны двигатель Cummins ISF 2.8, сценарий S1 и машина ГАЗель Next. Это старые синтетические материалы. По `AGENTS.md` такие данные в проекте не используем. Слайд — визуальная концепция и ориентир по стилю, а не источник данных, нормативов или ссылок на руководства.

## Что уже есть в продукте

- Режимы «Стандартный», «Новичок», «Крупный» (переключатель «Аа»). В режиме «Новичок» термины раскрываются по тапу, а после «Этапы работ» открывается пошаговый экран `/vehicles/{id}/steps` (`app/templates/steps.html`). Карточка вердикта «светофор» — на чат-экране.
- Чат с агентом, ссылки на руководство со страницами, заявка с подтверждением по команде механика.
- Журнал агента на `/admin/logs` (только чтение) и прогоны проверки.
