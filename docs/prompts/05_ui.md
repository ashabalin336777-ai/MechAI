# Промпт 5. Мобильный UI: гибрид B+E+D

Сверстай вертикальное мобильное PWA на Jinja2 + HTMX + Alpine.js по TZ.md §10 и макетам:
- docs/mobile_design/E_garage_steps.html (тема, крупные кнопки, один шаг)
- docs/mobile_design/B_agent_chat.html (карточки инструментов и цитаты)
- docs/mobile_design/D_toir_form.html (секции заявки)

Экраны: вход, выбор ТС/сценария S1–S5, шаги агента со статусом «агент работает», вопрос механику, черновик, подтверждение удержанием ~2 с и галочкой «данные проверил», номер заявки и ₽ сессии. Для S4 — отказ от диагноза без черновика.

Все тексты UI на русском. Ширина ориентир 390px, не ломать 360px. Добавь manifest.webmanifest (название «Цифровой механик»).

Поток HITL: HTMX/SSE показывает шаги; ask_mechanic останавливает граф; ответ механика возобновляет; токен подтверждения выдаёт ручка UI, затем граф вызывает submit.

Реальную запись с микрофона не делай обязательной: достаточно кнопок «Загрузить запись сценария S1…S5».
