# 05 · Мобильный UI (≈ 1,5 ч ночью + 3 ч утром) — F1, F2, F7, UX 15 баллов

Экраны по `docs/TZ.md` §11 (HTMX + Alpine.js + SSE, без сборщика фронта):
1. «Машина»: поиск/список 50 ТС (госномер, гаражный №, модель, двигатель), карточка ТС, выбор проверки (последняя по умолчанию, дата), большая кнопка **«Получить результат диагностики»**.
2. «Чат»: карточка вердикта «светофор» первой (иконка, 1 строка, уверенность %, качество записи, приоритет с основанием) → стрим ответа; ссылки `[док, стр. N]` раскрываются в цитату; быстрые кнопки «Этапы работ», «Можно ли ехать своим ходом?», «Создать заявку», «История машины»; блок «Как агент пришёл к выводу» (шаги из журнала); мелко «X с до ответа · N ток/с».
3. «Шаги»: этапы работ по одному на экран, «Готово → далее», источник под шагом.
4. «Заявка»: секции ТОиР (ТС, проверка, тип, диагноз, приоритет и основание, работы, запчасти, источники), галочка «Состав проверил» → «Отправить в ТОиР» → «✅ Заявка TKT-0001 создана».
5. Ошибки сервисов — понятный текст и кнопка «Повторить».
6. PWA: `manifest.webmanifest`, иконка, `theme-color`. 360–430 px, цели ≥ 48 px.
Стиль: ориентир — `docs/mobile_design/` (только визуал).

Приёмка: с телефона на стенде проходят С1, С2, С3 (TZ §8.1) без ошибок; вердикт читается за 10 с.
Деплой на стенд. Коммит + тег: `ui: mobile chat, verdict card, ticket screen` → `git tag mvp-f1-f7`.
