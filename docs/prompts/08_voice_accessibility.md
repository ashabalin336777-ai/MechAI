# 08 · Голос и адаптивность (≈ 3 ч) — пожелания заказчика

1. Голос (push-to-talk), `docs/TZ.md` §10: кнопка-микрофон → `MediaRecorder` webm/opus ≤ 30 с → `POST /api/stt` (multipart) → сервер → Neuraldeep `POST /v1/audio/transcriptions` (`model=STT_MODEL`, `language` из выбора или авто, `prompt` со словарём терминов) → текст в поле ввода для проверки → отправка. Аудио не сохранять. В журнал: `input_mode=voice`, язык, длительность, ₽ (1 ₽/мин).
2. Переключатель языка: ru, kk, uz, ky (бета), tg, tk, az, hy, ka, be, uk, hi. `lang` уходит агенту: ответ на этом языке, цитаты/обозначения/страницы/цифры — без перевода.
3. Режимы «Стандартный / Новичок / Крупный» (§11): CSS-переменные, localStorage/профиль, `ui_mode` агенту. Глоссарий `app/static/glossary_ru.json` (30–40 терминов) с подсказкой по тапу в режиме «Новичок».
4. (Если успеваем) TTS `qwen3-tts` для режима «Крупный»: кнопка «Прослушать ответ».
5. Согласие перед первым использованием микрофона (`consent_at`), ссылка на `/privacy`.

Приёмка: вопрос голосом по-узбекски/на хинди → распознанный текст → ответ на этом языке с русской цитатой и страницей; режим «Крупный» читается с вытянутой руки.
Коммит: `feat: voice input (whisper-1), languages, novice/large modes`.
