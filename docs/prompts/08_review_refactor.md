# Промпт 8. Код-ревью и рефакторинг

Сначала не меняй код: проведи ревью и выдай список проблем по приоритету.

Особенно проверь:
1. Auth: хеш PIN, lockout, JWT, CSRF, роль администратора не может submit.
2. HITL: токен только из UI, идемпотентность submit, аудит confirmed_by.
3. Цитаты: нет галлюцинаций page_id, сверка с chunks.jsonl.
4. App Platform: нет volumes и запрещённых директив, нет секретов в образе сверх env.
5. Утечки: PIN, токены, ключи в логах и шаблонах.
6. Тесты и eval S1–S5 зелёные.
7. Русский UI и мобильная вёрстка не разъехались.

Затем предложи минимальный рефакторинг (без смены стека и без нового скоупа). Вноси правки только после того, как я подтвержу список, либо если я сразу написал «исправляй критическое».

Если доступен Bugbot в GitHub PR — запусти ревью (комментарий `cursor review`); в редакторе для этого прохода предпочтительна модель Grok 4.7, не Composer Fast. Детали моделей: docs/models.md.
