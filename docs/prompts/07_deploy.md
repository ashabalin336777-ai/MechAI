# Промпт 7. Деплой на Timeweb App Platform

Подготовь репозиторий к деплою по TZ.md §13 и документации
https://timeweb.cloud/docs/apps/deploying-with-docker-compose

Проверь:
- Dockerfile и docker-compose.yml в корне, compose без запрещённых директив;
- порт приложения 8000, не 80/443;
- один сервис app первым в файле;
- миграции запускаются при старте контейнера и ходят в DATABASE_URL (DBaaS), не в локальный Postgres;
- данные синтетики копируются в образ;
- .env не в git, .gitignore полный; LICENSE (MIT) на месте;
- репозиторий публичный; автодеплой App Platform из публичного GitHub (подключение аккаунта, не URL);
- /health не требует авторизации;
- seed демо-данных можно повторить; если LLM недоступен — понятный режим деградации, без 500 и без скрытой подмены ответа модели;
- в README — шаги: публичный GitHub → Docker Compose → регион РФ → переменные/секреты панели → приватная сеть к Postgres → бакет S3 → включить pgvector; как проверить health и демо-вход;
- стенд не рассчитан на выключение после сдачи: он нужен до питча 1–3.12.

Не пиши реальные ключи. Если нужно, добавь скрипт проверки переменных (наличие имён, не значений).
