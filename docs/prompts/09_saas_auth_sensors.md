# 09 · SaaS, роли, 152-ФЗ, адаптер датчиков (≈ 3 ч, вырезается первым при отставании)

1. `AUTH_MODE=pin` (`docs/TZ.md` §12): табельный номер + PIN, argon2id, блокировка 5/15 мин, JWT httpOnly-cookie, роли mechanic / chief / admin. `AUTH_MODE=demo` остаётся по умолчанию (переключатель роли без входа) — стенд жюри открывается без логина.
2. `tenant_id` во всех запросах и в журнале; страница арендатора (название, тариф-идея, пользователи) — демо.
3. 152-ФЗ (§13): `/privacy`, согласие, хранение журнала `LOG_RETENTION_DAYS` (задача очистки при старте), без ПДн в логах. Список моделей в конфиге — только «в РФ».
4. Опционально **датчики/CAN** (§5.3): `mock/mock_sensors/app.py` (наша синтетика, детерминированная по паре id, согласованная с типом неисправности; J1939 для ЯМЗ, OBD-II для ЗМЗ), сервис `mock_sensors` (8003) в compose, `app/clients/sensors_client.py`, инструмент `get_sensor_telemetry` (регистрируется, только если задан `SENSORS_URL`). Агент сравнивает показания с нормами **только из RAG своего двигателя**; в UI плашка «Телеметрия: синтетика (демо)».
5. Тесты: PIN-хеш и блокировка, фильтр tenant_id, инструмент датчиков отключён без URL.
